# 对话资料库

## 第一次使用

1. 完整解压 Windows 便携包，启动 `MarkCraft.exe`。左上角展开侧栏，点「对话」，或从「视图 → 对话资料库」进入。
2. 在「对话来源与接续」查看本机检测结果。MarkCraft 检查当前用户的默认目录和客户端位置。首次打开时四个来源均未勾选，保存前不会扫描聊天正文。
3. 勾选你要使用的来源，核对目录，点「保存选择 → 完成」。如果使用便携安装、自定义环境变量或另一个配置目录，点「更改目录」。应选择下表里的**根目录**。首次运行智能体后产生的记录可用「刷新」读入。
4. 在左侧展开智能体和项目，点击会话。点「大纲」跳到当时的提问、回复或标题。在对话或 Markdown 视图中，点右上角的「导出」可保存完整对话。选择「Markdown 文稿 (.md)…」或按 `Ctrl + S` 可另存为 Markdown，也可选择 PDF、Word 等格式。Word 和其他 Pandoc 格式沿用文稿的导出依赖。

打开「管理来源」或「文件 → 设置 → 对话」可更改目录、撤回授权和查看接续组件。撤回后该来源从资料库消失，原智能体保存的文件仍由它管理。授权按 Windows 用户存储在 `%LOCALAPPDATA%\MarkCraft\chat-sources.json`。使用旧单独版本的用户，升级后也需首次选择来源。

## 本机来源

| 来源 | 默认记录根目录 | 开始接续前 |
| --- | --- | --- |
| Codex | `%USERPROFILE%\.codex`，支持 `CODEX_HOME` | 安装并登录 Codex。可从完成窗口打开桌面会话，或在对应目录运行提供的恢复命令。 |
| Claude Code | `%USERPROFILE%\.claude`，支持 `CLAUDE_CONFIG_DIR` | 安装并登录 Claude Code。完成窗口可复制进入工作区和执行 `claude --resume` 的命令。 |
| Antigravity | `%USERPROFILE%\.gemini`，支持 `MARKCRAFT_GEMINI_DIR` | 桌面与 CLI 共用此根目录。接续需 Windows 版 agy CLI 1.5.x、支持 node:sqlite 的 Node.js 22.13 或更高版本，以及有效的 CLI 登录。 |
| DeepSeek Harness | `%USERPROFILE%\.dsh`，支持 `DSH_HOME` | 浏览已有会话可直接启用。作为接收端时安装下面的插件，并运行 Harness。 |

根目录内通常可见 `sessions`（Codex、Harness）、`projects`（Claude）或 `antigravity`、`antigravity-cli`（Antigravity）。在目标客户端中也要使用同一个记录根目录。MarkCraft 按本机已写入的内容展示消息，资料库打开时约每三秒检查一次，回到窗口也会刷新。部分智能体版本、云端独有记录或缺少正文的会话可能无法读取。

如果提示目录无访问权限，请用生成记录的 Windows 账号打开 MarkCraft，并确认选的是该智能体的数据根目录。浏览需要该目录的读取权；创建接续副本需要目标记录目录的写入权。若组织策略限制访问，请联系该目录的管理员。

## 将任务交给另一个智能体

把会话拖到目标智能体或它的项目上，MarkCraft 会沿用默认标题和识别出的本机工作目录。想改名、核对目录或新开同一智能体的会话，可点右上角「接续…」，选接收端、名称和工作区。同一智能体接收时会创建独立分支。Codex 声明的目录过于宽泛时，MarkCraft 会参考已成功的文件操作推断项目；有歧义时可手动指定。粘贴 `codex://threads/…` 到「打开链接」，可以按 ID 找到已授权的本机会话。

接续保留可见的用户发言、助手回复、顺序及可用时间，目标直接使用所选目录中的已有文件。附件本体、未写入磁盘的内容、运行中的终端、工具权限和账号凭据不随会话复制。后续发言由目标智能体处理，长对话的上下文窗口和压缩策略由它决定。

### DeepSeek Harness

1. 解压完整的便携包，保持 `markcraft-handoff-0.3.0.tgz` 与程序在同一目录。启动并初始化一次 Harness 桌面端。
2. 在 MarkCraft 的「管理来源」启用 DeepSeek Harness 并保存。展开「原生接续组件」，点「安装接续插件」。MarkCraft 调用 Harness 自己的插件管理器，为当前用户的 desktop 配置安装。首次安装可能需要联网获取依赖。
3. 如果自动定位失败，点「选择 Harness 程序安装…」找到安装目录中的 `DeepSeek Harness.exe`。安装完成后重新打开 Harness，回到「管理来源 → 重新检测」。看到「插件已连接」就能把会话拖入。
4. 若显示已连接但没有工作区，请先在 Harness 中打开目标目录。接续完成后在 Harness 对应工作区点开新会话即可继续。

也可以在便携包目录打开 PowerShell，运行 `.\install-harness-plugin.ps1`；自选程序时使用 `-HarnessExecutable` 参数。已安装官方 DSH CLI 的用户可直接执行以下命令。退出插件时，在 Harness 的插件页停用或用最后一条命令卸载。

~~~powershell
dsh plugin --profile desktop add (Resolve-Path .\markcraft-handoff-0.3.0.tgz).Path
# 卸载时使用
dsh plugin --profile desktop remove markcraft-handoff
~~~

插件适配 Harness 0.2.2-rc.3。它只在本机回环地址接收请求，通过当前用户目录下的随机令牌校验。两个应用要使用同一个 Harness 配置目录。

### Antigravity

先安装 agy CLI 和 Node.js，并在终端执行 `agy acp --login` 完成原厂登录。登录和目标智能体的使用权限由用户直接与原厂客户端完成。MarkCraft 创建临时会话并用 agy 回读角色、原话和工作目录，校验成功后才登记原生副本。若 CLI 拒绝创建或恢复，请检查登录状态、CLI 版本及网络，然后重试。

选择「Antigravity 桌面端」后，可从完成窗口打开桌面应用，在对应项目下找到新会话；已打开的桌面端有时需要完整退出后再打开。选择 CLI 时可使用提供的恢复命令。接收端依赖本机原生会话格式，当前适配 1.5.x。单次 Antigravity 或 Harness 接续支持最多 16 MiB。
