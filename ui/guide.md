# 在 MarkCraft 里写作

打开程序就可以输入。选中文本按 **Ctrl + B** 加粗，输入 `## ` 写二级标题。按 Enter 分段，Shift + Enter 在段内换行。光标移出加粗、斜体等行内格式后，标记会收起。

## 文件与写作

- 自动保存默认开启。停笔约一秒后，已有文件写回原处，未命名文稿保存在「文件 → 草稿箱」。在草稿中按 Ctrl + S 可选定正式文件的位置。可在「文件 → 自动保存」关闭此功能。
- Ctrl + O 打开文稿，Ctrl + S 保存，Ctrl + Shift + S 另存为。新建窗口可以并排写两份文稿。
- Ctrl + P 搜索最近文件。「文件 → 打开文件夹」可浏览目录；Ctrl + Shift + 1 打开大纲。
- Ctrl + F 打开查找，Ctrl + H 展开替换。Enter / Shift + Enter 跳到下一处或上一处。F8 聚焦当前行，F9 将光标所在行保持在视野中部。
- 单击左下角「源码」或按 Ctrl + / 切换源码模式。当前行与每十行有行号，标题、列表和行内代码各有配色。
- 复制图片后可以在正文直接粘贴。已保存文稿的图片写入同目录的 `.assets` 文件夹。新文稿会把粘贴图片内嵌到 Markdown。
- 点击文内图片，再点当前路径即可选择替换文件。「输入路径」可填写相对路径或图片网址。「删除图片」从文稿中移除当前图片，按 Ctrl + Z 可撤销。

用「编辑 → 跳至行」或 Ctrl + Alt + G 定位。可以输入绝对行号、+5、50% 或 12:8（第 12 行，从行首右移 8 个字符）。

## 表格、代码和公式

右键单元格可调整当前列对齐、在指定一侧插入行列、删除行列或复制整张表的 Markdown。右键正文、链接、图片和代码块会显示各自的操作。按 Shift + F10 也能打开编辑区菜单。

| 操作 | 用途 |
| --- | --- |
| 点击单元格 | 在点击处输入；表格上方可设置列对齐、增删行列 |
| Tab / Shift + Tab | 切换到下一个或上一个单元格 |
| Ctrl + Shift + E | 将当前排版导出为 PDF |

编辑单元格时按 Enter 跳到下一行同列，Esc 撤回这次进入单元格后的输入。正文中的链接可单击打开，Alt + 单击可定位文字继续编辑。相对路径从当前文稿所在文件夹解析。其他程序修改文稿时，窗口会同步磁盘版本。两边都有改动时，选择「保留两版」即可把窗口内容存入草稿箱并查看磁盘版本。

在「段落」菜单插入代码块或公式块，也可以先选中文字再插入。点代码块右上角的语言名或「自动识别」，输入名称或简称即可查找语言，按 Enter 应用。点「选中代码」可选中整块代码正文。公式块中输入 LaTeX，下方会随输入预览。Ctrl + Enter 离开当前块。单击排好的代码或公式可以继续编辑。

行内公式示例 $E=mc^2$。使用「段落 → 流程图」可以插入 Mermaid 图。

## 设置与文件夹导航

按 Ctrl + , 或选择「文件 → 设置」。写作页可设置自动保存、正文主题、字号和宽度。「导航与图片」可设置大纲跟随和插图路径。改动会即时生效，重开后仍然保留。

Ctrl + P 按文件名打开文稿。Ctrl + Shift + F 在当前文件夹及子文件夹中查找正文，点击结果定位到对应行。在大纲顶端输入关键词可筛选标题，点击箭头可折叠章节。

「文件」侧栏顶部显示当前目录，悬停可看完整路径。点文件夹名称进入目录，点左边的小箭头则在原处展开或收起。点「上一级」回到父目录，用「后退」「前进」返回浏览过的位置。打开树中的文稿会保留目录和已展开的分支。

拖动表头的上边缘可移动整列，拖动正文行第一个单元格的左边缘可移动整行。浅色预览和落点线会跟随指针，松手后完成排序，Esc 取消。也可使用工具栏的「移行」「移列」。使用「文件 → 收集本文图片」可把图片复制到文稿旁的 `.assets` 文件夹；读取失败的图片会列出，仍沿用原来的路径。

## 导出与主题

「文件 → 导出 PDF」会询问保存位置。它导出当前正文，包括尚未保存的修改。纸张、页边距和页码可以在设置的「PDF 导出」页调整。更多导出格式包括 HTML、EPUB、ODT、RTF 和 LaTeX。

「文件 → 导出 Word」和工具栏的「导出 Word」都会打开排版窗口。先在左侧选择模板，在中间看当前文稿的第一页。首页默认整页居中显示。点「页宽」可放大查看，点「整页」可回到完整首页。右侧可展开「标题」「正文」「表格」调整六级标题字号、标题段前段后间距、字体、对齐、行距、首行缩进、表头底色和单元格上下内边距。左右面板可分别滚动。点「重置」可恢复当前模板。窄窗口中可用上方标签切换。预览就绪后点击「导出 Word…」选择保存位置。系统无法调用桌面版 Word 时会显示近似预览。

如果已有固定的页边距或页脚要求，把 Word 参考文件另存为 `%APPDATA%\MarkCraft\word-reference.docx`。再次打开导出窗口，左侧会出现「个人模板」。

默认的「澄明浅色」会自动显示多级标题编号。单独一行输入 [TOC] 可生成可跳转的目录。

在「主题」里切换浅色、深色，或打开主题文件夹修改 CSS 后重新载入。编辑主题时可以调整正文宽度、字号、行距、字体和强调色。

勾选任务可直接保存完成状态。点列表文字即可在原处编辑。行内公式旁边的文字可独立编辑，点公式本身才会展开 LaTeX。

正文中的脚注用上标数字表示。单击数字查看脚注，再单击回指箭头返回。代码块支持 Esc 或 Ctrl + Enter 回到正文。

## 段落操作与多选

指向段落，在左侧点六点手柄可改为正文或一至六级标题，也可在下方新建、复制、上移或下移。按住手柄上下拖动，在落点线处松手即可重排。段首箭头可折叠或展开，标题会收起下一级章节和正文，普通段落会收成一枚可点开的标记。折叠只影响当前窗口的显示。

用手指在正文左右轻扫，或用鼠标从段首手柄、正文两侧的留白横拖，即可进入多选。也可用「段落 → 多选段落」。逐段点选或点右侧圆圈，底部可转为待办、设定标题、全选、复制、剪切或删除。折起的章节作为一个整体复制、删除或移动。表格和代码块可整块移动、复制或删除，格式转换适用于正文与标题。按「完成」或 Esc 退出，正文修改可用 Ctrl + Z 撤销。

## 对话资料库

在「视图 → 对话资料库」勾选想使用的本机智能体，保存后通过侧栏浏览对话与项目。点「管理来源」可修改记录目录、撤回授权或安装 DeepSeek Harness 接续插件。将会话拖到目标工作区，或点「接续…」指定名称和目录。在 Markdown 视图按 Ctrl + S 可保存全文。便携包的「对话资料库.md」提供逐步安装和排错说明。
